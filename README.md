# Cube Atlas downloads

This public repository hosts installable Cube Atlas preview builds and its version feed. Application source remains private.

Download the current [Android and Windows 0.22 preview](https://github.com/desro13/cube-atlas-downloads/releases/tag/v0.22.0-preview). For automatic Windows updates, install through [CubeAtlas.appinstaller](https://raw.githubusercontent.com/desro13/cube-atlas-downloads/main/CubeAtlas.appinstaller).

The offline case library now has 1,031 named cases and 4,678 move options, including 302 ZBLS and 472 ZBLL cases adapted from [ZBTrain](https://github.com/loltreeman/ZBTrain) under MIT. ZBLL excludes the 21 PLL cases already listed separately. The virtual cube animates notation, lesson examples, and a selected case setup and move sequence. ZZ and Petrus have verified worked examples rather than complete case libraries. Bluetooth support is unchanged from the prior preview.

Android checks `update.json` on launch and offers a newer APK with Android installation approval. The Windows `.appinstaller` checks for signed MSIX updates. The MSIX uses the existing Cube Atlas test certificate.
